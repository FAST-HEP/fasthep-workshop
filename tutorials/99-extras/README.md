# Extras

These tutorials are advanced or integration-focused examples. They are useful
for trying complete workflows, but they are not part of the main numbered
workshop progression.

- [Partitioned ROOT Skim](partitioned-root-skim/) — run a nine-dataset dimuon
  analysis in partitions, reduce histogram products, and write one ROOT skim
  part per partition.
- [Per-Dataset Partitions](per-dataset-partitions/) — the same dimuon skim with
  a per-dataset chunk size (five partitions each), for running and listing one
  dataset at a time. Needs the per-dataset mode of `fasthep run`.
